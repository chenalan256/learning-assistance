# learning-assistance：互动式课程辅导

上传课件、作业题目或自己的练习答案，这个技能就能讲解章节、回答概念问题、批改答案和解答作业。还没提供材料时，它会先说明教学任务和后续安排。

## 可以怎样提问

- “请根据这份课件，给出这一章的学习任务。”
- “我没有看懂XX这个概念，请换一种简单的说法，并举例说明。”
- “以下是我的练习答案。请逐题批改，其中第 5、8、10 题详细讲解，其余正确题简要说明。”
- “请阅读这份课程作业并解答所有题目。”

## 完整讲解包含什么

如果你希望系统学习一个章节或主题，讲解会按顺序包含五个模块：

- 一、核心概念
- 二、例子
- 三、常见误区
- 四、练习测试题
- 五、一页笔记

例子的数量会按知识点和讲解需要决定。练习题通常有 8～12 道，你可以要求更多或更少。章节较长时可以分段讲解，每段会说明当前范围和后续主题。

## 怎样让回答更贴合你的需要

提问时可按需补充以下信息，不必每项都填写：

| 你可以指定 | 示例 |
| --- | --- |
| 学习范围 | “只讲第 2 章的顺序表，链表留到下一次。” |
| 基础与深度 | “我是初学者，先讲直觉，再给正式定义。”或“跳过基础定义，重点分析复杂度。” |
| 练习形式与数量 | “出 5 道从易到难的题，不附答案。” |
| 批改详略 | “第 3、7 题详批，其余正确题简评。” |
| 代码要求 | “算法题用 C 语言，给出完整函数并说明边界条件。” |
| 材料定位 | “请指出这个结论对应课件的哪一部分。” |

还没提供材料时，可以先说课程名称和想学习的方向；辅导会说明接下来可以怎样开展学习，并等待材料，不会猜测课件内容。材料中的说法若有歧义或不准确之处，辅导会说明适用前提及差别。针对单个概念的追问、答案批改和作业解答会按问题直接回答，不强套完整讲解的五个模块。
