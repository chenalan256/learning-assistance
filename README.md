# learning-assistance：互动式课程辅导

learning-assistance 是一个 Codex 技能。你可以提供讲义、练习题、作业或自己的答案，让它按你的学习进度讲解知识、回答疑问、设计练习、批改答案，并整理复习笔记。

它适合从一个章节开始系统学习，也适合只追问一个没听懂的概念。你可以指定学习范围、讲解深度、例子和练习的数量，以及答案需要简要还是详细。

如果暂时没有材料，也可以先说明课程和目标；技能会确认教学任务，等你提供材料后再开始针对性讲解。

## 可以怎样学习

### 学习一个章节

提供讲义并指出范围，技能会先检查本次范围内的主要知识点，再按以下顺序组织教学：

1. **核心概念**：说明定义、关键规则，以及相关概念之间的关系。
2. **例子**：用具体情境展示概念如何运用；你可以指定例子数量。
3. **常见误区**：说明容易混淆的地方和正确判断依据。
4. **练习测试题**：围绕已经讲过的内容出题，默认先不附答案。
5. **一页笔记**：汇总本次学习的定义、规则和易错点。

内容较多时可以分段学习。每段会说明已经讲到哪里、还有哪些内容待学；练习只考本段已讲过的知识。

> $learning-assistance 请根据我上传的生物学讲义，讲解“植物如何运输水分”。先用简单语言说明，再给出三个例子和练习题。

### 追问一个概念

指出具体卡住的地方，技能会聚焦解释，并用独立的小例子展示关键变化。你可以要求它放慢步骤、换一种说法，或比较两个容易混淆的概念。

> 我没理解为什么气压差会影响风向。请从一个简单情境开始，逐步解释每一步。

### 练习与批改

你可以请技能根据某个知识点另出题目，也可以提交题目和自己的答案，请它逐题批改。批改会区分正确、部分正确和错误，并检查题目的各个小问。你可以指定哪些题详讲，哪些正确题只需简评。

> 请围绕“化学反应速率的影响因素”出六道由易到难的练习题，先不要给答案。

> 下面是三道题和我的作答。请逐题批改：第一题简评，第二题和第三题写出详细推理过程。

### 解答作业

提供完整题目，并说明所需语言、格式和详略。技能会保留题目编号，回答所有小问；如果要求简化版，也会保留必要的定义、步骤或关键函数。需要代码时，可以指定编程语言和是否需要可运行的完整程序。

> 请解答这份统计学作业的全部题目。保留原题编号，每个小问分别作答，并说明计算所用的条件。

### 整理复习笔记

学完后，你可以要求把已经讲过的内容压缩成一页笔记，或指定只整理定义、公式、步骤、易错点等内容。

> 请把今天学过的光合作用内容整理成一页复习笔记，重点列出过程、影响因素和容易混淆的概念。

## 提问时可以补充什么

| 信息 | 说法示例 |
| --- | --- |
| 学习范围 | “只讲第二节，后面的内容下次再学。” |
| 当前基础 | “我刚开始学，请先解释直觉，再给正式定义。” |
| 讲解详略 | “每一步都展开说明。”或“只讲关键结论。” |
| 例子与练习数量 | “给三个例子，再出五道题。” |
| 批改方式 | “答对的简评，答错的详细说明原因。” |
| 作业格式 | “按原题编号，所有小问分别回答。” |
| 代码要求 | “使用 Python，给出可运行程序。” |

技能会以你提供的材料作为知识和题目的依据，并遵照你当前指定的范围、术语和符号约定。如果题目或材料缺少影响判断的关键信息，它会请你补充。
