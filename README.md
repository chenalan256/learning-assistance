# learning-assistance：互动式课程辅导

上传课件、作业题目或自己的练习答案，这个技能就能讲解章节、回答概念问题、批改答案和解答作业。还没提供材料时，它会先说明教学任务。

## 快速开始

1. **提供材料**：直接上传课件或作业文件，或粘贴要学习的段落、题目和自己的答案。材料较长时，指出本次的章节、主题或题号。
2. **说清这次的任务**：例如完整讲解、解释一个概念、生成练习、批改答案或解答作业。可以同时指定难度、题量、详讲的题号及编程语言。
3. **接着追问**：对不懂的地方要求换一种说法，做完练习后提交答案，需要复习时请它整理要点。

## 提问范例

- “请根据这份课件，给出这一章的学习任务。”
- “我没有看懂XX这个概念，请换一种简单的说法，并举例说明。”
- “以下是我的练习答案。请逐题批改，其中第 5、8、10 题详细讲解，其余正确题简要说明。”
- “请阅读这份课程作业并解答所有题目。”

## 完整讲解的五个模块

系统学习一个章节或主题时，讲解按顺序包含五个模块：

- **一、核心概念**：用易懂的语言讲清定义、概念之间的关系、操作规则和适用条件；需要时说明复杂度。
- **二、例子**：展示具体输入、关键变化和结果，帮助你看懂概念如何使用。
- **三、常见误区**：指出错误判断会在什么情况下出错，以及正确依据。
- **四、练习测试题**：围绕本次已讲内容检查理解，通常兼顾概念、操作、边界和应用。
- **五、一页笔记**：把重要定义、规则和易错条件压缩成便于回看的条目或表格。

例子的数量会按知识点和讲解需要决定。练习题通常有 8～12 道，默认不提前附答案；你可以要求更多或更少。章节较长时可以分段讲解，每段会说明当前范围和后续主题，练习只考本段已经讲过的内容。你可以在学完一段后说“继续下一段”，或先要求补讲没听懂的地方。

提供材料并说“开始学习这一章”“完整讲解这个主题”，会直接进入教学。材料和主题明确时，这句“给出这一章的学习任务”也会直接进入完整讲解。如果你现在只想安排进度，请明确说“只制定学习计划，暂时不要讲解”。

## 按学习场景使用

### 追问概念

适合卡在某个术语、定义或推导步骤时使用。指出没听懂的部分，以及希望换成什么讲法；回答会聚焦这个问题，而不是重新讲整章。前面已经整理过的知识要点会用于后续追问，必要时才回查材料中的相关部分。

> 我还是不懂抽象数据类型与具体存储实现的区别。请先用生活中的例子解释，再用栈说明；最后解释空栈执行 `pop` 为什么也属于操作规则。

### 生成同风格练习

提供原作业或说明考点，可以指定题量，并要求改变数据和操作情境、按由易到难排列。默认不提前给答案；做完后可以继续提交答案，让辅导逐题批改。

> 请参考这份作业中的顺序表插入、删除题，另出 5 道同风格练习，从易到难。不要照搬原题的数据，先不要给答案。

### 批改练习答案

把题目和对应答案一起提供，并标明需要详讲的题号。辅导会逐题判断正确、部分正确或错误；正确题可以简要说明依据，错误或未完成的题会解释原因、正确过程和关键边界，不只给分数或标准答案。

> 以下是第 1～10 题的题目和我的答案。请逐题批改：第 5、8、10 题详细讲解，其余正确题简要说明；凡是答错的题，都指出错在哪里并给出正确思路。

对某题的判定仍有疑问时，可以接着问“第 8 题为什么不是 O(1)？”或“请逐步说明指针更新顺序”。

### 解答课程作业

提供完整题目和必要条件，说明希望使用的编程语言、代码完整度和讲解重点。请求解答整份作业时，辅导会覆盖所有题目；算法题会说明思路、复杂度和必要前提。代码在条件允许时会用代表性输入验证。

> 请解答下面两道链表作业题，使用 C 语言给出完整函数。分别说明思路、时间与辅助空间复杂度，并检查空链表、单结点和指针更新顺序。

### 整理复习笔记

除了完整讲解末尾的“一页笔记”，你也可以在讨论结束后单独要求整理已学内容，并指定笔记重点，例如定义、操作步骤、复杂度或易错点。

> 请把今天讲过的顺序表插入与删除整理成一页复习笔记：列出操作步骤、移动元素的范围、复杂度和最容易混淆的边界条件。

## 补充提问信息

提问时可以补充以下信息：

| 你可以指定 | 示例 |
| --- | --- |
| 学习范围 | “只讲第 2 章的顺序表，链表留到下一次。” |
| 基础与深度 | “我是初学者，先讲直觉，再给正式定义。”或“跳过基础定义，重点分析复杂度。” |
| 练习形式与数量 | “出 5 道从易到难的题，不附答案。” |
| 批改详略 | “第 3、7 题详批，其余正确题简评。” |
| 代码要求 | “算法题用 C 语言，给出完整函数并说明边界条件。” |
| 材料定位 | “请指出这个结论对应课件的哪一部分。” |

还没提供材料时，可以先说课程名称和想学习的方向；辅导会说明接下来可以怎样开展学习，并等待材料，不会猜测课件内容。材料中的说法若有歧义或不准确之处，辅导会说明适用前提及差别。针对单个概念的追问、答案批改和作业解答会按问题直接回答，不强套完整讲解的五个模块。
