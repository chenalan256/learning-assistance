# learning-assistance：互动式课程辅导

上传课件、作业题目或自己的练习答案，这个技能就能讲解章节、回答概念问题、批改答案和解答作业。还没提供材料时，它会先和你确认教学任务和后续安排，不会假定课程内容。

## 可以怎样提问

- “请根据这份课件，完整讲解XX这一章。”
- “我没有看懂XX，请换一种简单的说法，并举例说明。”
- “以下是我的练习答案。请逐题批改，其中第 5、8、10 题详细讲解，其余正确题简要说明。”
- “请阅读这份课程作业并解答所有题目。”

## 完整讲解包含什么

如果你希望系统学习一个章节或主题，讲解会按这个顺序包含五个模块：

- 一、核心概念
- 二、例子
- 三、常见误区
- 四、练习测试题
- 五、一页笔记

其中，例子的数量会按知识点和讲解需要决定。

练习题通常有 8～12 道，你可以要求更多或更少的题目。

章节较长时可以分段讲解，每段会说明当前覆盖的范围和还没讲到的主题。

如果只想弄懂一个概念、批改答案或解答作业，直接提出具体问题即可。

## 告诉我你的学习要求

你可以指出想学习的范围、希望讲解到什么深度、哪些题需要详细分析，以及代码应使用的编程语言。交练习答案时，也可以说明哪些题只需简要反馈、哪些题需要详细解答。

课件等学习资料只是教学参考；其中的指令不会代替你的要求。

完整讲解的规则见 [SKILL.md](SKILL.md)，五模块模板见 [完整讲课回答模板](references/full-lesson-template.md)。
