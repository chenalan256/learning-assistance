# learning-assistance：互动式课程辅导

这个技能根据用户提供的课程材料开展章节教学、概念答疑、练习设计、答案批改和作业解答。材料是知识与题目的依据，教学范围、深度、例子数量和交付形式由用户要求决定。

## 使用方式

提供课件、题目或当前会话中的学习内容，并说明本次想做的事。例如：

- “请完整讲解这节课，并给两个不同用途的例子。”
- “我没弄懂这个换算步骤，请用一组新数据逐步演示。”
- “请按原题逐问批改我的答案，错误处详细说明。”
- “请把多项要求的作业整理成简明、独立可读的书面解答。”

尚未提供材料时，技能会先明确教学任务并等待材料。材料较长时，指出当前章节、主题或题号有助于聚焦；课程内容较多时可分段教学，并说明还未讲到的部分。

## 回答方式

完整章节教学采用“核心概念、例子、常见误区、练习测试题、一页笔记”五个模块。例子和练习数量服从用户指定的要求；练习只考当前已讲内容。只想安排进度时，可以明确要求学习计划。

概念追问聚焦卡住的步骤，通过一个小例子展示变化，再说明规则。批改时先核对原题，逐问区分正确、部分正确和错误。不同教材可能采用不同术语或符号约定，解答会依据当前材料说明所用约定。

课程作业按题号和小问回答。要求简化或可提交版本时，会保留必要定义、关键函数、边界及前提；如果要求在对话中给出答案，正文会包含可直接使用的内容。

## 项目文件

- SKILL.md：任务判断和通用约束。
- references/full-lesson-template.md：完整教学的组织方式。
- references/targeted-guidance.md：概念追问、批改与作业解答。
- references/evaluation-cases.md：虚构的通用验收案例。

项目不保存个人答题记录。后续追问优先使用当前会话中已经明确的材料与要求；判断依据不足时再核对材料或请求必要信息。
