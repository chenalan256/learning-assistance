# 完整讲课回答模板

仅在用户要求完整章节或主题教学时使用。标题可以写课程或主题名称，标题后可用一两句话交代本次范围；正文只使用下列五个同级模块，并保持标题文字和顺序一致。可以在模块内使用更小的标题、表格和代码块，但不要增设第六个同级教学模块。

```markdown
# 章节或主题名称

## 一、核心概念

## 二、例子

## 三、常见误区

## 四、练习测试题

## 五、一页笔记
```

## 各模块写法

- **一、核心概念：**先用简单语言说明概念、用途和相互关系，再讲清必要的定义、结构、操作步骤、前提和复杂度。覆盖本次材料中的主要考点；不要只给知识点清单。这里可用一句话帮助理解，但完整的场景演示留到“二、例子”。
- **二、例子：**按教学需要决定数量，不设上限或固定值。选择能覆盖不同关键概念的例子，逐步展示输入、变化过程、结果及它证明的知识点；涉及代码时走查关键状态。
- **三、常见误区：**独立列出容易混淆或用错的地方，说明错误发生的条件和正确判断依据。不要把例子的步骤放到本节，也不要把本节并入例子。
- **四、练习测试题：**通常给出 8～12 题，覆盖本次已讲的主要内容，并兼顾概念理解、操作过程、边界条件与综合应用。写清必要的输入输出、下标或位置约定；默认不附答案，用户要求解答时再给出。用户指定题量时遵从用户要求。
- **五、一页笔记：**把已讲内容压缩为便于复习的一页摘要，保留最重要的定义、规则、复杂度和易错条件；不引入尚未讲解的新内容。

## 使用边界

针对性追问、答案批改和作业解答按问题本身组织，不套用上述五模块。章节需要分段时，明确每段范围与尚待讲授的主题；一段完整教学仍按该模板写，概览不得冒充整章讲解。
