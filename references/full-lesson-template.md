# 完整讲课回答模板

仅在用户要求完整章节或主题教学时使用。标题可以写课程或主题名称，标题后用一两句话交代本次范围；正文只使用下列五个同级模块，并保持标题文字和顺序一致。可以在模块内使用更小的标题、表格和代码块，不增设第六个同级教学模块。

```markdown
# 章节或主题名称

## 一、核心概念

## 二、例子

## 三、常见误区

## 四、练习测试题

## 五、一页笔记
```

## 篇幅控制

完整讲课默认以约 2500～3500 个汉字为目标，通常不超过 4000 字；练习题和“一页笔记”计入篇幅，代码只保留讲清知识点所需的片段。短主题不必凑字数。先压缩重复解释、相似例子与冗长题干，不靠省略主要考点来缩短回答。若一章内容难以在此篇幅内讲清，应明确本次范围并分段教学，说明后续还要学习什么。用户明确要求更详细、完整代码或不同篇幅时，遵从用户要求。

## 各模块写法与分界

- **一、核心概念：**用简单语言讲清本段内容的概念、相互关系、必要定义、操作规则、适用条件和复杂度。完整的场景演示留到“二、例子”，不要在这里重复演算。
- **二、例子：**数量由知识点决定，不设固定个数。挑选各有教学作用的例子，展示输入、关键变化和结果；只解释这个例子新增的理解，不复述概念段落。
- **三、常见误区：**独立指出错误判断、它在什么条件下会出错，以及正确依据；不要重演例子的完整过程。
- **四、练习测试题：**通常给出 8～12 题，逐题编号，兼顾概念、操作、边界和应用；只考本次已经讲授的范围。写清必要约定，默认不附答案；用户指定题量时遵从用户要求。
- **五、一页笔记：**用简短条目或表格压缩本段最重要的定义、规则、复杂度与易错条件，不再展开解释，也不引入新知识。

## 使用边界

针对性追问、答案批改和作业解答按问题本身组织，不套用上述五模块。章节分段时，每段只讲当前范围，例子和练习也只覆盖已讲内容；明确尚待讲授的主题，概览不得冒充整章讲解。
